CSV format

One row per observation.

  • species (required; euring code, code, or name)
  • age, sex (both optional, default to unknown; either the EURING code or the display label works for each, e.g. "9" or "4CY", "M" or "Male")
  • date (required; YYYY-MM-DD)
  • time (optional; HH:MM)
  • location, region, country (all required; region and country narrow which location a name means -- either the EURING code or the display label works for region/country. Creates a new location, from this row's own latitude, longitude, and accuracy, if none matches all three)
  • latitude (decimal; required to add a new location, otherwise optional)
  • longitude (decimal; required to add a new location, otherwise optional)
  • accuracy (metres; required to add a new location, otherwise optional)
  • observer (required; the observer's name -- created if none matches)
  • notes (optional)
  • left_above, left_below, left_wing, nasal_saddle, neck_collar, right_above, right_below, right_wing (one column per tag position; each optional, but at least one must be present and, for a given row, at least one must have a value)

Each position column holds the tag(s) worn at that position only, e.g. a right_below of "BW(A123)" or, for two rings stacked at the same position read top to bottom, "O,Y". Inscriptions are written as read top to bottom too; anything about which way they read belongs in the notes.

The coordinates override those for the location, for this sighting only. Values are saved to 4 decimal place, giving a positional accuracy of 10m.
