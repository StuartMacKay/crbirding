CSV format

One row per project.

  • name (required)
  • coordinator (required)
  • country (required; either the EURING code or the display label)
  • contact (optional; the email address observations should be sent to)
  • submit (optional; the website where observations should be submitted)
  • site (optional; the website describing the project)
  • description (optional)

There's only ever one project per country -- a row naming a country that already has one is skipped rather than creating a duplicate.
