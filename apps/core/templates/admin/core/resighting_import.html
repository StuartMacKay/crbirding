{% translate "CSV format" %}

One row per resighting. Required columns: species (EURING code), location (its numeric id), date (YYYY-MM-DD), and tags. Optional columns: time, latitude, longitude, accuracy, notes -- coordinates given here override the location's own, for this sighting only.

tags uses the same notation shown elsewhere in the app: positions separated by ;, tags stacked at one position separated by ,, e.g. LB:WB(A123)u;RB:O,Y -- a white-on-blue ring reading upward on the left leg (tibia), and an orange ring above a yellow ring on the right leg (tarsus). Direction, if given, is a single letter (u/d/h) right after the closing bracket.
