CSV format

One row per rule.

  • species (required; euring code, code, or name)
  • position (required; euring code or the display label)
  • regex (required; a valid regular expression)
  • coordinator, project (identify the project the rule belongs to; at least one of the two is required per row -- if both are given, they must name the same project)

A row matching an existing rule's species, position, regex, and project exactly is skipped rather than creating a duplicate.
