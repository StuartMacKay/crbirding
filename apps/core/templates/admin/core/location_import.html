CSV format

One row per location.

  • name (required)
  • region, country (both required; either the EURING code or the display label works for each -- country narrows which region a name means, since region labels aren't unique across countries)
  • latitude (decimal; required)
  • longitude (decimal; required)
  • accuracy (metres; optional)
  • notes (optional)

A row matching an existing location by name and region (matching is case-insensitive) is skipped rather than creating a duplicate; its coordinates are left as they are. A row matching none creates a new location.

Coordinates are saved to 4 decimal places, giving a positional accuracy of around 10m.
