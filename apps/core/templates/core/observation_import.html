Import observations from CSV

Bring in your own historical sightings, or a whole life history a project has sent back for one bird -- one row per observation.

CSV format

  • species (required; EURING code, scientific name, or common name)
  • date (required; YYYY-MM-DD)
  • time (optional; HH:MM)
  • location, region, country (all required; region and country narrow which location a name means, the same way they do on the web form -- either the EURING code or the display label works for region/country. If no existing location matches all three, a new one is created from this row's latitude, longitude, and accuracy, which must then all be given)
  • latitude, longitude (decimal; required to add a new location, otherwise optional -- overrides an existing location's own, for this sighting only)
  • accuracy (metres; required to add a new location, otherwise optional)
  • observer (required; the observer's name -- created if no existing observer has that name)
  • notes (optional)
  • left_above, left_below, left_wing, nasal_saddle, neck_collar, right_above, right_below, right_wing (one column per tag position; each optional, but at least one column must be present and, for a given row, at least one must have a value)

Each position column holds only the tag(s) worn at that position, e.g. a right_below of "BW(A123)" or, for two rings stacked at the same position read top to bottom, "O,Y". Inscriptions are written as read top to bottom too; anything about which way they read belongs in the notes.

Re-running an import is safe -- a row that matches one already recorded is skipped rather than duplicated. An observer who isn't you (a life history often names several) shows up on their own My Observations, not yours.
